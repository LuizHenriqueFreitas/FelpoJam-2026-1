# INKMANCER

**Inkmancer** é um jogo desenvolvido para a **FelpoJam 2026** pela **Equipe Avelino**. O projeto possui classificação indicativa para a faixa de **10-12 anos**.

O objetivo do jogador é auxiliar Avelino, um mago que manipula o poder da tinta e dos carimbos, a derrotar todos os adversários em seu caminho.

---

## Comandos e Compatibilidade

O jogo está disponível para **Windows** e **Linux**, com suporte para teclado e mouse.

| Comando | Ação |
| :--- | :--- |
| **WASD** | Movimentação |
| **Clique Esquerdo** | Ativar modo de invocação / Confirmar invocação |
| **1 - 2 - 3 - 4** | Selecionar carimbos de invocação no inventário |
| **Esc** | Abrir menu de configurações |
